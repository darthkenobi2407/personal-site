smart parking system

a smart parking system using an arduino (later an esp32), two ir sensors and a servo motor. it tracks how many parking slots are full or empty and displays the count on the arduino serial monitor. the plan is to later show it on a webpage hosted by the esp32.

simple antivirus

a very simple antivirus that uses hash matching with the virustotal api. it's pretty simple, but cool nevertheless. you can check it out here. so how it works is that it takes a file and calculates its hash and then checks if that hash is in the virustotal database and if it is then it means that the file is malicious and if it isnt then it means that the file is safe its a very simple antivirus but its a good starting point for learning about how antiviruses work and how to make them better and it helped me understand how antiviruses work and how to make them better and it helped me understand how to use the virustotal api and how to use hash matching to detect malicious files
